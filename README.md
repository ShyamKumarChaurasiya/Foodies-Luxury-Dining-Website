# 🍽️ Foodies – Luxury Dining Website

A modern and elegant luxury restaurant website built using **HTML5, CSS3, Bootstrap 5, and JavaScript**. Foodies presents a premium dining experience through a sophisticated gold-and-black theme, refined typography, interactive UI elements, and responsive layouts.

🔗 **GitHub Repository:** https://github.com/ShyamKumarChaurasiya/Foodies-Luxury-Dining-Website

---

## 📌 About the Project

Foodies is a frontend restaurant website designed to showcase a luxury dining experience.

The website includes a visually appealing landing page, restaurant story, signature menu, guest testimonials, frequently asked questions, reservation call-to-action, and newsletter subscription section.

The primary goal of this project was to improve my frontend development skills by combining HTML, CSS, Bootstrap, and JavaScript to create an elegant and responsive user interface.

## ✨ Features

- 🎨 Elegant luxury gold-and-black theme
- 🧭 Fixed navigation bar with scroll effects
- 📱 Responsive navigation menu using Bootstrap
- 🍽️ Hero section with dining experience highlights
- 📊 Animated counters using JavaScript
- 📖 Restaurant story and about section
- 🥘 Signature menu cards with food images and prices
- ⭐ Guest testimonials carousel
- ❓ Frequently Asked Questions section
- 🪑 Reservation call-to-action sections
- 📧 Newsletter subscription UI
- 🖼️ Image hover effects and smooth transitions
- 📱 Responsive layouts for desktop, tablet, and mobile devices

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and content |
| CSS3 | Custom styling, animations, and layouts |
| Bootstrap 5 | Responsive grid system and UI components |
| JavaScript | Navigation scroll effects and animated counters |
| Font Awesome 5 | Icons and visual elements |
| Google Fonts | Cormorant Garamond and Jost typography |

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/ShyamKumarChaurasiya/Foodies-Luxury-Dining-Website.git
```

### 2. Navigate to the Project Folder

```bash
cd Foodies-Luxury-Dining-Website
```

### 3. Run the Website

Open the `index.html` file in your preferred web browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.
